# 🔐 OnyxWallet - Solana Wallet in Telegram

## 💎 Your Key to Solana - Right in Telegram

### 🌟 Main Features
- **Send/receive SOL and tokens** without leaving Telegram
- **Pay friends via @username** - no address copying
- **Full control** over your funds (non-custodial)
- **Swap tokens** at best rates
- **NFT support** - view and transfer your collectibles

## 🚀 How to Use

### 1️⃣ Get Started
Simply open [@OnyxWalletBot](https://t.me/OnyxWalletBot) in Telegram and:
```plaintext
/start - Create your wallet
/help - See all commands
/balance - Check your SOL and token balances
```

## Manage Your Crypto
```plaintext
/deposit - Get your deposit address
/history - View transaction history
```

## Send & Receive
```plaintext
/send 1 SOL @friend - Pay by Telegram username
/send 5 USDC 7xAbC... - Send to any Solana address
/receive - Show your QR code for deposits
```

## Advanced Features
```plaintext
/swap 1 SOL→USDC - Exchange tokens
/nft list - View your NFT collection
/stake - Earn rewards by staking
```

## 🔒 Your Security First
- You own your keys - encrypted and protected
- 2FA protection for sensitive actions
- Instant freeze if Telegram is compromised

```plaintext
/freeze - Lock your wallet immediately
/recover - Restore access if needed
```
